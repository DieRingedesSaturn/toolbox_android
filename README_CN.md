# Toolbox

[English](README.md)

Toolbox 是一个以按需读取为主的轻量 Android 工具箱；另可在明确设置后开启通知快速记账。账本使用本机 SQLite，可选择手动触发 WebDAV 同步；应用无需登录账户，也不依赖固定服务器。实时监控仅在用户主动启动后运行，并使用用户可见的前台服务。

账本菜单中的「通知快速记账」可选开启 Android 通知读取，并选择来源应用。应用只在本机对这些新通知提取数字金额（含 `¥`、`￥`、`元` 写法）；最近 7 天最多保留 30 条候选。点选金额会预填现有编辑器，仍由你确认保存。候选项不保存通知正文；关闭功能会清空候选项。系统授予的通知读取范围较广，来源应用筛选发生在 Toolbox 收到通知之后。此功能不会主动联网，也不启动常驻前台服务。

开发前请阅读英文开发规范 [AGENTS.md](AGENTS.md)。完整目录约定和后续功能的落位规则见 [docs/PROJECT_STRUCTURE_CN.md](docs/PROJECT_STRUCTURE_CN.md)。

## 当前范围

- `Device`：手机身份、Android/API、内核、SoC/CPU、ABI、核心数、内存、存储、显示、电池，以及基础 GPU 能力摘要。
- `Live monitor`：可选的紧凑半透明悬浮窗折线图，显示 CPU、GPU、内存、电量和 FPS 参考值，并可自定义显示项目。监控页按核心显示 CPU 当前频率，同时显示 GPU/显示详情和热状态详情；悬浮窗可在逐核心频率和按峰值频率加权的 CPU 占比之间切换。CPU/GPU 优先读取真实占用率；Android 只提供频率时用 `≈` 标记频率占比估算，受系统限制的源明确显示不可用。
- 监控页还会在公开 API 提供时显示电池温度、Android 系统热状态、热余量、当前显示刷新率和支持的显示模式。悬浮窗与整个软件均支持 Everforest 自然森绿深浅主题配色（深色、浅色、跟随壁纸的动态色与自定义主题色），自适应文字与图表高对比度；悬浮窗支持锁定位置与触控穿透，移动后会保存上次位置。
- `Location`：按需获取当前位置，显示十进制度/DMS 坐标、精度、提供方、GPS 提供方高度、时间、按需卫星扫描中实际观测到的导航系统及可用/已启用定位源，并支持按需查询地表地形海拔（DEM 模型）。只有用户开始定位后才请求前台位置权限。
- `Network`：按需显示连接方式、接口、本地地址、DNS、网关和按流量计费状态；公网 IP、IP 大致地理位置与运营商查询是单独的手动操作。
- `Ledger（记账与平均使用成本）`：支持日常收支记账，分为概览（本月收支、支出分类、近 6 个月收支趋势——点月份跳到该月明细、最近记录）、明细（按日分组、按月切换）、成本（大件摊销与订阅日均）与账户四个标签页，可左右滑动切换，内置收支分类，并可在记账时开启「计入平均成本」，区分**一次性长期大件（如买断手机/电脑的按日、按月折旧摊销）**与**周期性订阅（按周/月/季/半年/年或自定义每N天/周/月/年，日均月均折算与续费追踪）**。使用 Android 原生 `SQLiteOpenHelper` 持久化，内置 `uuid`、毫秒级时间戳与软删除墓碑，按「最后写入者胜」合并；不依赖任何固定服务器。每次数据库结构升级前，会先把旧数据库文件复制到不参与备份的应用私有目录（保留最近 3 份），即使升级逻辑出错，升级前的数据也还在；目前还没有一键恢复按钮。主屏幕小组件显示日均成本与本月支出，并提供快速记一笔按钮；不需要额外权限，记录变化时即时刷新，并由系统小组件调度器约每 3 小时更新，不运行后台服务。本地备份通过系统文件选择器完成：JSON 导出为完整可再导入的备份（含删除标记），CSV 导出为表格；导入时可选择「合并」或「替换」，全程不需要存储权限。记账页菜单还提供手动 WebDAV 备份与同步：仅在用户主动点击时运行，仅支持 HTTPS，且只写入你在服务器上预先创建的文件夹（`ledger.json`、按日期命名的 `ledger-backup-*.json` 快照——仅保留最新 10 份，可将快照下载后通过「替换」导入恢复——以及 `ledger-backups.json` 索引）。密码经 Android Keystore 加密后仅保存在本机，不新增权限、依赖或后台任务。由于账本不参与系统自动备份，当距上次 JSON 导出或 WebDAV 同步（从未备份时按最早的数据算）已满 7 天、且这期间账本有改动时，记账页会显示备份提醒，可直接导出 JSON 或 WebDAV 同步；点「稍后」隐藏 7 天。可选的月度预算（总额与按标签，单位人民币，在记账页菜单或概览本月卡片中设置）会显示进度条、剩余或超支金额，以及本月剩余每天可用多少；预算只保存在本机，不包含在 JSON 备份和 WebDAV 同步中。新建记录时，近 90 天里记过至少两次的名称会显示为「常用」按钮，点一下即可填好类型、名称以及最近一次的金额、币种、标签和账户；这些按钮由已有记录推算，不额外保存或同步任何数据。记录支持自定义多标签（原 12 个内置分类仅在旧记录引用时转为可编辑标签；新安装不再预置标签）。标签可重命名、换色、从推荐预设选 emoji、排序、合并，并可对多选记录批量添加/移除；标签详情页显示笔数与累计收支。明细与成本页可按标签以「任一/全部」筛选，概览页按标签统计支出。周期订阅与周期性固定收入按期确认：待确认卡片按日历日期列出到期续费，每次记录的续费会成为一条独立交易并锁定当日汇率（已跳过的续费不再提示）；在某日停订时，恰在当天的续费不算已扣款。两种成本模式都可以设置可选的结束日期（必须晚于记账日期）：当天仍然计入，之后不再计入；订阅不会生成落在该日或之后的续费，一次性资产改按从记账日到该日的天数摊销（代替预计使用天数），到期后显示为「已摊销完」，并退出日均成本统计。一次性大件可在所选日期「卖出」或「报废」：卖出会生成一条关联的收入记录，最终成本为买价减去卖价；已处置的大件不再计入日均成本，且可撤销。账目币种支持人民币（CNY，默认）、日元（JPY）、美元（USD）与欧元（EUR）：外币账目在保存时锁定当日的 CNY 汇率，因此所有合计、摘要、小组件与成本计算始终统一为人民币，历史总额不会随汇率波动。汇率按显式的按需回退链获取——Frankfurter（api.frankfurter.dev）→ 欧洲央行官网（www.ecb.europa.eu）→ 社区 currency-api（cdn.jsdelivr.net，其次 *.currency-api.pages.dev）——请求仅携带日期或日期范围，实际使用的来源会记录在每条账目中（手动输入记为 manual）；所有来源失败时可选择最近缓存汇率或手动输入。每条账目都记在一个账本上——账户页（第 4 个标签）可管理多个账户（名称、币种、期初余额与日期、颜色、图标），显示各账户余额与按缓存汇率折算的人民币总资产（缺少汇率的账户不计入并标注）。账目类型支持支出、收入与账户间转账；转账不计入收支统计；账户详情里的「校准余额」会在计算余额与实际不符时写一条有符号的余额调整记录（调整只显示在该账户的流水里，不进入明细列表，也不计入收支统计）。账户与账目、标签一样走 LWW 备份/WebDAV 载荷。
- `Currency converter（汇率换算）`：以欧元为基准的参考汇率，按回退链获取且无需 API Key——Frankfurter（api.frankfurter.dev）→ 欧洲央行 eurofxref（www.ecb.europa.eu）→ 社区 currency-api（cdn.jsdelivr.net，其次 *.currency-api.pages.dev）；界面会标注实际使用的来源，社区来源的数值可能与欧洲央行略有差异。输入金额并选择源币种（四个记账币种在前，另可展开全部已发布币种并显示本地化名称；在列表里点星标可把常用货币固定到记账币种旁边，同时出现在币种按钮和换算结果中），按各币种自身小数位换算。汇率仅在你主动点击刷新（或首次「获取汇率」）时联网获取，随后缓存到本机（最新汇率 + 近期历史日期）供离线使用，并始终标注汇率日期与来源；发送到这些主机的只有请求日期。
- Device 页与各模块所有信息行点击即可复制。

v0.1 暂不实现测速、Shizuku/root、进程管理、第三方重型 ORM 或广告分析。基于 Shizuku 的高级权限数据读取属于后续计划，不是当前依赖。

## 实时监控权限

启动实时监控需要 `SYSTEM_ALERT_WINDOW`，用户需在系统设置中允许悬浮窗；同时声明前台服务权限，并在 Android 13+ 请求 `POST_NOTIFICATIONS`，以显示服务状态和停止操作。监控每秒采样一次，可从监控页或通知停止，不会开机自启。普通应用可能无法读取系统级 CPU/GPU 占用文件，界面会如实说明限制，不伪造数据。电池温度、系统热状态和热余量使用 Android 公开 API；精确 CPU/GPU 温度及厂商专用 GPU 占用率在没有受信任系统权限时可能不可用。FPS 项目当前以显示刷新率作为尽力而为的参考值；跨应用真实渲染 FPS 需要 SurfaceFlinger 特权访问，留给后续 Shizuku 计划。

位置模块仅在用户主动开始定位时申请 `ACCESS_COARSE_LOCATION` / `ACCESS_FINE_LOCATION` 前台权限，不申请后台定位；地表地形海拔（DEM）仅在用户手动点击后单次查询。网络状态使用系统自动授予的 `ACCESS_NETWORK_STATE` 和 `INTERNET` 权限；公网 IP 与地理位置操作只在手动触发时向公开地址服务发起一次请求，不会自动轮询。

账本包含财务记录，因此关闭 Android 系统自动备份；请使用账本内的手动 JSON 导出或 WebDAV 同步备份。WebDAV 服务器必须为已有的 `ledger.json` 提供强 ETag 并支持条件写入，否则应用会在覆盖前停止同步。应用流量总计按 UID 去重；共享或无法识别的 UID 流量无法归属到单个应用或分类，读取失败时显示不可用。卫星导航系统列表只显示实际观测到的星座。

## 开发环境

- Android Studio Quail 3 (2026.1.3 Patch 1)
- Android SDK Platform 36、Build Tools 36.0.0、Platform Tools 37.0.1
- JDK 17
- Kotlin + Jetpack Compose
- minSdk 26，targetSdk 36

使用 Android Studio 打开仓库并让 Gradle 同步配置的依赖。命令行流程为：

```bash
./gradlew assembleDebug
./gradlew installDebug
./gradlew installRelease
adb logcat
```

Debug 构建没有 R8 优化，也用不上随包的 baseline profile，Compose 界面明显更慢；日常使用请安装 release 构建。项目根目录下存在不提交的 `signing/toolbox-debug.keystore` 时，debug 和 release 都用它签名，两者可以互相覆盖安装，数据不丢；没有这个文件时，debug 回落到默认调试密钥，release 不签名。release 构建不可调试，`adb shell run-as` 读不到应用文件，备份请用 App 内的 JSON 导出或 WebDAV。

如果当前 shell 尚未配置 JDK 17 和 Android SDK，请将 `JAVA_HOME` 与 `ANDROID_SDK_ROOT` 指向本机安装位置。SDK 路径保存在不提交的 `local.properties` 中。
