# Toolbox

[English](README.md)

Toolbox 是一款按需读取的轻量 Android 工具箱：设备信息、实时监控、定位、网络、应用用量、天文星历，以及本机记账、汇率换算和 TOTP 令牌。账本和令牌保存在本机，无需登录，也不依赖固定服务器。悬浮窗监控、WebDAV 同步、模拟位置等可选功能都要你主动开启后才会运行。

当前版本 **0.1**（`minSdk 26`，`targetSdk 36`）。

## 功能

- **设备信息**：型号、系统、SoC/CPU、内存、存储、显示、电池和基础 GPU 摘要；各信息行可复制。
- **实时监控**：按核心查看 CPU 频率与占用，以及 GPU、内存、电池和热状态。可开启半透明悬浮窗折线图（前台服务，不会开机自启）。系统不提供真实占用时显示为不可用，或以 `≈` 标记频率占比估算。FPS 目前是显示刷新率参考，不是跨应用真实帧率。悬浮窗开着时，监控页复用它的采样，不再各读一份。悬浮窗位置在拖动结束时保存。
- **位置**：按需定位、地名、十进制度/DMS、精度、GNSS 星空图，以及手动查询地形海拔。另有「模拟位置」供开发者测试（需在开发者选项中指定本应用；会话限时 15/30/60 分钟，带常驻通知）。**仅供学习与合法测试。**
- **网络**：本机连接信息；点一下再查询公网 IP / GeoIP / 代理风险提示；可取消的局域网设备扫描（含摄像头端口启发式提示，并非完整发现）。
- **应用用量**：需「使用情况访问」权限。按今天、昨天、7 天、30 天查看前台时长和流量。
- **天文星历**：根据坐标生成夜间天体时间线，可导出图片。没有定位结果时使用默认坐标（北京），界面会标明这是默认参考坐标。
- **记账与成本摊销**：本机 SQLite 账本（多账户、标签、预算、订阅摊销、转账）。成本卡片默认显示精简摘要，点击展开详情与操作，长按复制。明细支持搜索并多选标签筛选，点击月份可直接选择年月。支持加密 JSON 备份/导入、明文 CSV 导出、手动 HTTPS WebDAV 同步（文件放在自动创建的 `Toolbox/ledger/` 子目录），以及主屏幕小组件。**通知快速记账暂时关闭**（菜单入口已隐藏，通知监听组件默认禁用）。相关代码保留，之后可以重新打开。通知正文不再以明文写入本机偏好设置，启动时会清掉已经存下的正文。
- **汇率换算**：按需拉取参考汇率（Frankfurter → 欧洲央行 → 社区 currency-api），结果带日期和来源，可离线使用缓存。
- **TOTP**：RFC 6238 令牌（相机或相册扫码、手动输入）。本机 Android Keystore 加密，页面开启防截屏；可用你设置的密码导出加密备份，或同步到你配置的 HTTPS WebDAV 下的 `Toolbox/totp/` 子目录。本机库无法解密时保持原样，同步不会覆盖已有令牌。
- **隐私**：打开部分系统会藏起来的 Google 与系统设置（Google 设置、定位精确度、广告、使用情况与诊断、电话号码验证，以及若干系统页面）。只会启动已导出的界面。
- **外观**：系统/深色/浅色主题，动态取色、Everforest、鼠尾草或自定义强调色；可选一张背景图片并调节强度，强调色也可从图片取色。点击预览可进入全屏编辑，单指拖动、双指缩放，保存后生效，取消则保留原设置；缩放不再使用滑块。图片只保存在本机，无需权限。

首页、记账月汇总和小组件的月结余按「收入 − 日常支出 − 当月已入账的月付订阅」计算；自定义每 1 个自然月也视为月付。年付、周付等周期款只计入实际付款的那个月，记一次性支出，进入实际支出、预算和账户余额，不摊进结余。日均持有成本按全部在用资产与订阅周期摊销，界面只展示日均和折合每年，不把摊销月均当成每月真实支出。续费仍需确认入账，不会为尚未记录的月份虚构付款。预算、账户余额、交易明细和实际收支图表保留全部已记账金额。续费根据所属订阅（含软删除的原记录）判断周期；原订阅缺失、无法判断周期的续费仅计入实际支出。成本卡片收起时最多显示两个标签，展开后显示所有有效标签；资产、订阅、固定收入的分组标题采用不同底色。

首页不再显示标题栏。首页与设置是两页桌面式左右滑（读屏可通过无障碍操作打开设置）。关于收进设置，设置按外观、首页、备份、关于分子菜单。自定义空行数量保持不变；网格稍微超出可用高度时，优先压缩空行高度和行距，工具卡片与状态摘要保留实际尺寸，大字体也不会被强行压小。内容确实放不下时才允许滚动。长按编辑期间暂停翻页手势，并显示悬浮的「完成」按钮。

## 备份与恢复

在设置里配置一个或多个 HTTPS WebDAV 基础文件夹，分别为记账和 TOTP 绑定服务。手动同步会依次创建 `Toolbox/` 和对应的 `ledger/`、`totp/` 子目录。新目录的主文件不存在时，优先读取旧的共享 `Toolbox/` 文件，其次读取配置的基础目录。旧文件不会被删除或改写，已有的明文账本备份仍是明文，需要你自行清理。

记账 JSON 导出和 WebDAV 内容采用用户密码加密，与 TOTP 一样使用 PBKDF2-HMAC-SHA256（600,000 次迭代）和 AES-256-GCM。记账密码只在当前记账页面会话中保留，共用备份的设备需输入相同密码。请另外妥善保存，遗忘后无法找回。CSV 导出、本机账本 SQLite 仍为明文；快照文件名和索引只暴露时间等元数据，不包含记录正文。

主文件同步成功后会尝试保存一份唯一命名的快照，索引保留最新十份。记账和 TOTP 菜单中的「历史备份与恢复」可按服务列出版本，包括旧目录索引中的历史版本。当前与旧目录的版本统一按创建日期分组、从新到旧排序，每份单独显示到毫秒的时间。刷新和恢复均须点击触发。先预览有效记录数、确认替换，再恢复；恢复前会保存加密的本机副本，也可从该菜单找回。文件替换导入同样先备份可读取的当前数据。恢复会生成新修订，并为被省略的本机记录写入删除标记，下次手动同步传播这些修改。

设置 → WebDAV 中另有「软件设置备份」。它固定使用配置列表的首个服务，不依赖记账/TOTP 的服务绑定；加密的 `settings.json` 和最新十个历史版本保存在 `Toolbox/settings/`。仅包含语言、主题、排序、监控选项、常用货币、模拟位置精度等通用偏好，不包含 WebDAV 凭据或配置、账本数据、TOTP 令牌和 Android 权限。恢复前可预览设置项数，并保存当前设置的加密副本。外观立即更新，其他偏好重新打开相应页面后加载。

修改输入或记住的备份密码**不会给旧备份换密**。旧导出文件、历史快照、恢复前副本仍需原密码。对已有远端库同步/备份时会先解密，因此直接改用新密码会在写入前失败。新生成的本地导出使用新输入的密码。WebDAV 登录凭据与备份加密密码互相独立；目前没有自动换密迁移。

主文件和快照索引要求服务器提供强 ETag，并使用条件写入。多个服务会先读取合并再逐个写回，逐项报告失败。这是手动整文件 Last-Write-Wins 同步，不是跨服务器原子事务；其他设备或服务器同时修改时，可能需要再次同步。

## 安装与构建

用 [Android Studio](https://developer.android.com/studio) 打开本仓库，或在命令行：

```bash
./gradlew assembleDebug
./gradlew installDebug      # 调试包，无 R8，界面较慢
./gradlew assembleRelease   # 日常使用建议装已签名的 release
./gradlew testDebugUnitTest
```

环境：JDK 21（应用字节码目标仍为 Java 17）、Android SDK Platform 36。把 SDK 路径写在不提交的 `local.properties` 里。

debug 包在项目根目录存在不提交的 `signing/toolbox-debug.keystore` 时用它签名，否则用默认调试密钥。没有单独配置发布密钥时，release 仍使用这把原始密钥。需要用专用发布密钥签名时，在不提交的 `keystore.properties` 或环境变量里配置：

| `keystore.properties` | 环境变量 |
| --- | --- |
| `storeFile` | `TOOLBOX_RELEASE_STORE_FILE` |
| `storePassword` | `TOOLBOX_RELEASE_STORE_PASSWORD` |
| `keyAlias` | `TOOLBOX_RELEASE_KEY_ALIAS` |
| `keyPassword` | `TOOLBOX_RELEASE_KEY_PASSWORD` |

`storeFile` 可以是绝对路径，或相对于项目根目录的路径。没有完整的发布签名配置时，release 会回退到存在的 `signing/toolbox-debug.keystore`；该文件也不存在时才不签名。

## 权限

下列权限都是使用对应功能时才申请，或只是安装期声明、本身不会打开功能。

| 权限 | 用途 |
| --- | --- |
| 精确/粗略位置 | 位置读取、天文定位；只有你开始定位时才申请，不申请后台位置 |
| 使用情况访问（`PACKAGE_USAGE_STATS`） | 应用用量与流量 |
| 查询全部应用（`QUERY_ALL_PACKAGES`） | 解析用量列表里的应用名。安装期声明；若上架 Play，属于受限权限 |
| 悬浮窗、前台服务、通知 | 实时监控悬浮窗；模拟位置会话的状态通知（Android 13+ 会申请通知权限） |
| 通知监听 | 为通知快速记账声明。该功能暂时关闭，监听组件默认禁用 |
| 相机 | TOTP 扫码，用时再申请 |
| 网络 / 网络状态 / 组播 | 公网 IP、汇率、海拔、地图瓦片、WebDAV、局域网扫描（扫描进行中才加入组播） |
| 模拟位置（`ACCESS_MOCK_LOCATION`） | 仅用于出现在开发者选项的模拟应用列表；声明本身不会开启模拟 |

系统自动备份已关闭（账本和令牌属于敏感数据）。请用应用内的 JSON 导出或 WebDAV 同步备份。

定位地名由系统地理编码器解析，可能会联网。公网 IP、海拔、汇率、地图瓦片和 WebDAV 都只在你主动操作时访问对应服务。
